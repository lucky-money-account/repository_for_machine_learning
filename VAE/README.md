# VAE · 变分自编码器（从零实现）

从数学推导到代码实现的 VAE 实践。配套推导笔记见 [`VAE--从数学理论开始.md`](./VAE--从数学理论开始.md)。

## 内容

- `VAE_basic.ipynb` —— 卷积 VAE（眼镜人脸数据集，256×256）：编码器输出 μ / σ、重参数化、ELBO 训练、先验采样与潜空间编辑。
- `AE.ipynb` —— 普通自编码器（MNIST），作为 VAE 的对照。
- `VAE--从数学理论开始.md` —— ELBO / 重参数化 / 高斯 KL 闭式解的推导笔记。
- `test/` —— 潜空间属性编辑（加 / 摘眼镜）的输入与结果示例。

## 说明

- 数据集（`Images/`，约 466MB）与训练权重（`model/VAEglasses.pth`，约 253MB）体积过大，不随仓库提供。
- 运行环境：PyTorch（`d2l` conda 环境）。

## 关键点

- 潜空间编辑用 **μ（确定性编码）** 而非采样得到的 z，结果稳定、可复现。
- 属性方向 `Δ = mean(μ | 戴眼镜) − mean(μ | 不戴眼镜)`，沿 `±Δ` 遍历即可让一张脸加 / 摘眼镜。
- 用随机方向做对照，验证 Δ 确实在控制“戴眼镜”这一属性。
