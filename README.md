## 两个总结

### 神经网络训练的本质

通过梯度下降最小化损失函数，找到一组最优参数（权重与偏置）。拆解为六个环节：

1. **目标** —— 让损失函数 L(θ) 尽可能小，它衡量预测与真实标签的差距
2. **核心工具** —— 梯度 ∇L(θ) 指向上升最快的方向，反方向即下降最快方向（局部贪心）
3. **优化器** —— 决定如何利用梯度更新参数（步长、动量等），影响下降效率与稳定性
4. **学习率调度器** —— 动态调整步长，前期快速下降、后期精细搜索
5. **激活函数** —— 引入非线性，否则多层线性叠加等价于单层线性模型
6. **反向传播** —— 用链式法则高效求出每个参数的偏导数

最终目的是让模型在未知数据上表现良好，即**泛化能力**。

### 深度学习训练流程

```
取一个批次的数据
  → 前向传播得到预测
  → 计算损失
  → loss.backward()        反向传播计算梯度
  → optimizer.step()       根据梯度更新参数
  → optimizer.zero_grad()  清空梯度，准备下一批次
  → 重复直到遍历完所有批次（一个 epoch 结束）
  → 进入下一个 epoch
```

### 模型推理调用

- `model.eval()` —— 切换到评估模式：关闭 Dropout；BatchNorm 使用训练阶段统计好的均值方差
- `torch.no_grad()` —— 禁用梯度计算，节省显存与计算时间，避免意外梯度累加
- 遍历测试集，用 `torch.argmax(outputs, dim=1)` 取预测类别，`(predicted == y).sum().item()` 累加正确数，最后算准确率
