## 5.1 层和块

### 为什么需要这一节

`nn.Module` 是 PyTorch 组织网络的基本单元。一切网络（`nn.Linear`、`nn.Sequential`、自定义 MLP）都是「块」。理解块 = 理解网络怎么被组织。

### 核心概念（面试高频）

- **块（Module）的本质**：一个块 = 参数的容器 + `forward` 定义的计算。
- **两个方法分工**：`__init__` 定义子层（不传数据），`forward` 调用子层（传数据）。
- **块可以嵌套**：块里放块（NewMLP 里嵌 Sequential，NewSequential 里嵌 NewMLP）。

### 自己的例子（mynet 的 NewSequential）

```python
class NewSequential(nn.Module):
    def __init__(self, *args):
        super().__init__()
        for idx, block in enumerate(args):
            self.add_module(f'layer{idx}', block)   # 字符串键注册
    def forward(self, X):
        for block in self._modules.values():        # 顺序调用
            X = block(X)
        return X
```

`nn.Sequential` 内部就是这么干的：一个「有序字典 + 顺序调用」，没有魔法。

### API 速查

| 操作 | 写法 | 说明 |
|---|---|---|
| 自定义块 | `class X(nn.Module):` | 继承 nn.Module |
| 必须调用 | `super().__init__()` | 注册参数靠它 |
| 注册子层 | `self.add_module(name, module)` | 键是字符串 |
| 前向 | `def forward(self, X)` | 定义计算 |
| 有序容器 | `nn.Sequential(...)` | 内部 = add_module + 顺序调用 |
| 触发前向 | `net(X)` | 自动调 forward |

### 踩坑（自己踩过）

- `self._modules[block] = block`：键写成模块对象 → 报「can only concatenate str (not "Linear") to str」。
- 忘写 f-string：`'layer{i}'` 字面输出，应写 `f'layer{i}'`。

## 5.2 参数管理

### 为什么需要这一节

搭好网络后，要访问、初始化、共享参数——训练的本质就是在更新这些参数。

### 核心概念（面试高频）

- **state_dict**：`{参数名: 张量}` 字典，参数的「快照」。
- **Parameter vs 普通张量**：只有 `nn.Parameter` 会被 `parameters()` 收集、被优化器更新（这是本章最核心的认知）。
- **参数绑定**：两层共享同一参数（等价于权重共享）。

### 自己的例子（mynet 的 state_dict）

```python
net.state_dict()
# OrderedDict([('layer0.weight', ...), ('layer0.bias', ...),
#              ('layer4.rand_weight', ...), ('layer4.rand_bia', ...), ...])
# rand_weight/rand_bia 能出现，正是因为它们用了 nn.Parameter
```

### API 速查

| 操作 | 写法 | 说明 |
|---|---|---|
| 参数快照 | `net.state_dict()` | 参数名 → 张量 |
| 参数迭代 | `net.parameters()` | 喂给优化器 |
| 带名迭代 | `net.named_parameters()` | (名字, 参数) 对 |
| 访问某层 | `net[0].weight` / `net[0].bias` | |
| 正态初始化 | `nn.init.normal_(t, mean, std)` | 带 `_` = 原地 |
| Xavier | `nn.init.xavier_uniform_(t)` | 稳定方差 |
| Kaiming | `nn.init.kaiming_uniform_(t)` | 配合 ReLU（CNN 常用） |
| 共享参数 | `net[1].weight = net[0].weight` | 参数绑定 |

## 5.4 自定义层

### 为什么需要这一节

进阶：不只是组合已有层，而是从零造一个新层。

### 核心概念

- 不含参数的层：只重写 `forward` 即可。
- 含参数的层：用 `nn.Parameter` 手动注册。
- 最底层：`torch.autograd.Function` 手写 forward + backward。

### 自己的例子（mynet 的 HiddenLayer）

```python
class HiddenLayer(nn.Module):
    def __init__(self, in_chan, out_chan):
        super().__init__()
        self.rand_weight = nn.Parameter(torch.rand(in_chan, 64))  # 可训练参数
        self.linear = nn.Linear(64, out_chan)
        self.rand_bia = nn.Parameter(torch.rand(64))
    def forward(self, X):
        X = X @ self.rand_weight + self.rand_bia
        X = F.relu(X)
        X = self.linear(X)
        X = X / X.sum()   # 归一化
        return X
```

### 踩坑（自己踩过）

- `torch.rand(..., requires_grad=True)` 不是 `Parameter` → `parameters()` 收集不到、优化器不更新。
- `X ** 0.5` 对负数开根号 → NaN。改成 `X / X.sum()`（但 `X.sum()=0` 时仍会除零，注意）。

## 5.5 读写文件

### 为什么需要这一节

训练好的模型要持久化：存档、读档、迁移到别的机器。

### API 速查

| 操作 | 写法 |
|---|---|
| 保存张量 | `torch.save(obj, 'path')` |
| 读取 | `torch.load('path')` |
| 保存参数 | `torch.save(net.state_dict(), 'mlp.params')` |
| 加载参数 | `net.load_state_dict(torch.load('mlp.params'))` |

注意：保存的是 `state_dict()`（只存参数，不存结构）；加载时模型结构要自己重建好。

## 一句话总结

> ① 层和块 = 搭积木，② 参数管理 = 管积木的零件（Parameter 是关键），③ 延后初始化 = 自动猜尺寸，④ 自定义层 = 自己造积木，⑤ 读写 = 存档读档，⑥ GPU = 换更强的引擎。
