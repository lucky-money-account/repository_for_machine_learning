## 3.1 线性回归

### 为什么需要这一节

深度学习的所有模型都是线性回归的扩展：本节是「模型 + 损失 + 优化」三个组件的第一次完整闭环。理解这一节，等于拿到全书训练流程的骨架。

### 直觉

- 模型 = 一条直线（高维是超平面）ŷ = Xw + b。目标：让直线尽量贴合所有数据点
- 损失（均方误差 MSE）= 预测值与真实值差值的平方的均值。损失越小 = 直线越贴合
- 优化（梯度下降）= 朝「损失下降最快」的方向（负梯度）一步步调 w、b——2.4 的爬山类比在这里落地

### 核心概念（面试高频）

- **解析解 vs 迭代解**：线性回归有解析解（正规方程一步解出最优 w），但深度学习模型一般没有解析解，所以学梯度下降这种「迭代逼近」方法
- **小批量随机梯度下降**：每次随机抽一小批样本算梯度。快；梯度噪声反而帮助跳出局部最优。「随机」来自 shuffle
- **泛化**：模型在没见过的数据上的表现（第 4 章正则化正式展开）

### 公式

- 模型：ŷ = Xw + b
- 损失：L = (1/n) Σ(ŷᵢ − yᵢ)²
- 更新：w ← w − lr · ∂L/∂w

## 3.2 线性回归的从零开始实现

### 为什么需要

亲手写一遍训练循环的每个组件（数据 → 模型 → 损失 → 更新），才能理解高级 API 内部在做什么，也才能看懂之后的报错。

### 核心代码模式（训练循环骨架，全书通用）

```python
for X, y in data_iter:
    l = loss(net(X, w, b), y)     # ① 前向 + 损失
    l.sum().backward()            # ② 反向求梯度
    sgd([w, b], lr, batch_size)   # ③ 更新参数（内含清梯度）
```

### 手写组件速查

| 组件 | 写法 | 要点 |
|---|---|---|
| 生成数据 | `y = X@w + b + 噪声`，`y.reshape(-1, 1)` | reshape 让标签成列向量，与预测形状对齐 |
| 数据迭代 | `random.shuffle(indices)` + `yield` | 随机性来自 shuffle |
| 初始化参数 | `w = torch.normal(0, 0.01, (2,1), requires_grad=True)`；`b = torch.zeros(1, requires_grad=True)` | |
| 前向 | `X @ w + b` | |
| 损失 | `((y_hat - y) ** 2) / 2`，`l.sum().backward()` | 用 sum 则梯度是批内之和 |
| 更新 | `with no_grad(): param -= lr*grad/batch_size; param.grad.zero_()` | 三件套 |

### 踩坑

- 梯度会累加：每轮更新后要清梯度，否则越累越大
- 叶子节点：更新必须 `torch.no_grad()` + 原地 `-=`，否则 w 变非叶子、`w.grad` 变 None
- 同一张图不能二次 backward：前向必须放循环内，每轮重建图
- loss 用 `sum()` → 梯度是「批内样本梯度之和」，要除 batch_size 求平均；用 `mean()` 则不用除
- 标签 reshape 成 `(n,1)`：与预测值形状对齐，防止 `(n,1)-(n,)` 错误广播成 `(n,n)`

## 3.3 线性回归的简洁实现

### 为什么需要

手写的重复劳动（建参数、写损失、写更新）用框架封装。真实项目都用高级 API，其内部就是 3.2 的手写逻辑。

### 从零 ↔ 简洁 一一对照（面试高频）

| 手写（3.2） | 高级 API（3.3） |
|---|---|
| `w`、`b` 两个张量 + `linreg` 函数 | `nn.Linear(2, 1)`（参数 + 公式打包成一个层） |
| `squared_loss` 函数 | `nn.MSELoss()`（默认 mean，不用 sum + /batch_size） |
| `sgd` 函数 | `torch.optim.SGD` + `step()` |
| `w.grad.zero_()` | `trainer.zero_grad()` |
| `data_iter` 函数 | `data.DataLoader`（shuffle + 切批 + yield 一行搞定） |
| `[w, b]` 手动列参数 | `net.parameters()`（自动收集） |

### 核心 API 速查

| 组件 | 写法 |
|---|---|
| 模型 | `net = nn.Sequential(nn.Linear(2, 1))` |
| 参数初始化 | `net[0].weight.data.normal_(0, 0.01)`；`net[0].bias.data.fill_(0)` |
| 损失 | `loss = nn.MSELoss()` |
| 优化器 | `trainer = torch.optim.SGD(net.parameters(), lr=0.03)` |
| 数据 | `data_iter = data.DataLoader(dataset, batch_size, shuffle=True)` |

### 训练循环范式（全书通用）

```python
trainer.zero_grad()   # 清梯度
l.backward()          # 反向
trainer.step()        # 更新
```

## 3.4 softmax 回归

### 为什么需要

线性回归预测「一个连续值」，softmax 回归解决「分类」——输出每个类别的概率。两者结构几乎一样，只差输出层和损失函数。

### 直觉

- 网络输出 C 个分数（C = 类别数），分数可大可小、没有概率意义
- softmax = 对分数取 exp 再归一化 → 变成「和为 1」的概率分布
- 交叉熵损失 = −log P(正确类别)：模型越确信正确类别，损失越小

### 核心概念（面试高频）

- **softmax**：exp 归一化。用 exp 的原因：① 保证概率为正；② 指数放大差距，让最大分数更突出
- **交叉熵损失**：本质 = 最大似然的负对数（2.6 的那条线在这里落地）。面试必问「为什么最小化交叉熵 = 极大似然」
- **为什么分类不用 MSE**：MSE 对 softmax 输出的梯度在预测很离谱时反而很小、收敛慢；交叉熵梯度大、学得快
- 网络：`X @ W + b`，W 形状 `(输入维, 类别数)`

## 3.6 softmax 回归的从零开始实现

### 为什么需要

手写 softmax + 交叉熵 + 准确率统计，看清分类训练和回归训练的区别。

### 手写组件

- softmax：exp + 按行归一化（`keepdim=True` 控制广播方向——2.1 的 keepdim 在这里派上用场）
- 交叉熵：`-log(y_hat[range(n), y])`，只取「正确类别」位置的概率
- 准确率：预测类别 == 标签类别的比例

## 3.7 softmax 回归的简洁实现

### 核心 API

- 模型：`nn.Linear(784, 10)`（输入 784 维，输出 10 类）
- 损失：`nn.CrossEntropyLoss()`（内部已含 softmax + 交叉熵）
- 训练循环与 3.3 完全一样：`zero_grad → backward → step`

### 踩坑

- `CrossEntropyLoss` 的输入是**未经过 softmax 的分数（logits）**，不是概率——外面不要再多加一层 softmax（新手最高频错误）
