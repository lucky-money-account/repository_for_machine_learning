## 2.1 数据操作

### 为什么需要这一节

深度学习里的一切——数据、模型参数、中间结果、输出——都装在同一个数据结构里：**张量（tensor）**。张量可以理解为「带 GPU 加速能力的多维数组」。

### 直觉

- 0 维张量 = 标量（一个数）
- 1 维 = 向量（一列数）
- 2 维 = 矩阵（行 × 列）
- 3 维及以上 = 高阶张量。一张 RGB 图是 `(C, H, W)`（通道、高、宽），一批图是 `(N, C, H, W)`（批量数在前）——这个 NCHW 约定贯穿全书。

### 核心 API 速查

| 操作 | 写法 | 说明 |
|---|---|---|
| 创建序列 | `torch.arange(n)` | 0, 1, ..., n-1 |
| 形状 | `x.shape` | 返回 `torch.Size` |
| 元素总数 | `x.numel()` | number of elements |
| 变形 | `x.reshape(a, b)` | 元素个数不变 |
| 全 0 / 全 1 | `torch.zeros((2,3))` / `torch.ones(...)` | 默认 float32 |
| 指定值填充 | `torch.full((2,3), 7)` | |
| 从列表创建 | `torch.tensor([[1,2],[3,4]])` | |
| 均匀随机 | `torch.rand(2,3)` | 取值 [0, 1) |
| 标准正态随机 | `torch.randn(2,3)` | 均值 0、方差 1 |
| 拼接 | `torch.cat((A,B), dim=k)` | 沿第 k 轴拼接；该轴尺寸相加，其余轴不动 |
| 求和 | `x.sum()` | 返回 0 维张量 |
| 转 numpy | `x.numpy()` | 共享内存，改动会互相影响 |
| numpy 转 tensor | `torch.tensor(nd)` | |
| 索引 / 切片 | `X[0]`, `X[1:3]`, `X[1,2]` | 与 Python 列表语法一致 |
| 原地操作 | `x += 2` 或 `x.add_(2)` | 下划线后缀表示原地修改 |

### 广播机制（面试高频）

两个形状不同的张量做逐元素运算时，框架会自动把小的「逻辑扩展」到与大的对齐（实际不复制内存）。规则：

1. 从右往左逐维对齐；
2. 两个维度相等、或其中一个为 1、或其中一个缺失，则相容；否则报错。

例：`(2,3) + (3,)` 合法（(3,) 视作 (1,3) 再扩展）；`(2,3) + (2,1)` 合法；`(2,3) + (2,)` 报错。

### 原地 vs 非原地（面试高频）

- `x + y` 返回新张量，`x.add_(y)` 原地修改旧张量。
- 深度学习训练里，反向传播要重放前向的每一步计算；原地修改会破坏这条链，所以对需要梯度的张量做原地操作通常直接报错。

## 2.2 数据预处理

### 为什么需要

真实数据永远是「脏」的：有缺失值、有文本类别。模型只接受数字张量，所以要先洗成「全数字、无缺失」。

### 核心流程与 API

| 步骤 | 写法 | 说明 |
|---|---|---|
| 读取 csv | `data = pd.read_csv(file)` | |
| 按位置切分 | `data.iloc[:, :]` | 前一个冒号选行，后一个选列 |
| 填缺失值 | `inputs.fillna(inputs.mean())` | 数值列常用均值填充 |
| 类别变数值（哑变量） | `pd.get_dummies(data, dummy_na=True)` | 每个类别变成一列 0/1 |
| 转张量 | `torch.tensor(df.values)` | `.values` 只取数据，不含索引列 |

- 缺失值两种思路：数值列用均值填充；类别列当作一个额外的「缺失」类别（`dummy_na=True`）。
- one-hot（哑变量）思想：类别没有大小关系，把「装修=精装」变成一列 0/1，避免模型误以为类别可以比大小。第 3 章成都房价的特征工程会大量用到（面试高频）。

## 2.3 线性代数

### 为什么需要

神经网络的每一层，本质就是**矩阵乘法 + 加法**。线性代数是网络运算的语言。

### 矩阵乘法 = 线性变换（面试高频）

- 矩阵 A 乘向量 x，就是把 x 旋转 / 拉伸 / 压扁到新位置：`Ax = y`。
- 网络一层接一层 = 变换套变换：先拉伸、再旋转、再压扁……多层叠加就能拟合复杂的形状。
- 特征向量：被矩阵作用后方向不变的向量（只被缩放 λ 倍），即 `Ax = λx`。

### 张量 vs 矩阵（面试高频）

- 矩阵固定 2 维，张量任意维。
- 深度学习强调「Tensor」的原因：数据天然多维（N,C,H,W）；GPU 硬件按张量组织计算；框架用统一的张量管理数据、参数和梯度。

### API 速查

| 操作 | 写法 | 说明 |
|---|---|---|
| 转置 | `A.T` | |
| 复制 | `A.clone()` | 独立新内存 |
| 逐元素乘（哈达玛积） | `A * B` | 对应位置相乘 |
| 向量点积 | `torch.dot(x, y)` 或 `torch.sum(x*y)` | |
| 矩阵-向量乘 | `torch.mv(A, x)` | |
| 矩阵-矩阵乘 | `torch.mm(A, B)` 或 `A @ B` | |
| 按轴求和 | `A.sum(axis=k)` | 把第 k 根轴「压掉」求和 |
| L1 范数 | `torch.abs(x).sum()` | 绝对值之和 |
| L2 范数 | `torch.norm(x)` | 平方和开根号（欧氏距离） |
| Frobenius 范数 | `torch.norm(A)` | 矩阵元素平方和开根号 |

- 降维求和的直觉：`sum(axis=k)` 就是把第 k 根轴压扁，该轴在结果形状中消失。
- 范数 = 向量/矩阵的「长度」。L2 最常用（几何距离）；L1 会让参数趋向稀疏（很多变成 0），第 4 章权重衰减还会遇到（面试高频）。

## 2.4 微积分

### 为什么需要

训练 = 调参数让损失变小。往哪个方向调？梯度给方向。

### 概念直觉（面试高频）

- 导数 = 变化率：x 动一点点，f 动多少（函数在该点的斜率）。
- 偏导数 = 多维函数中固定其他变量，只对一个变量求导。
- 梯度 = 所有偏导数拼成的向量，指向函数**增长最快**的方向。类比爬山：梯度是「最陡的上山路」，沿负梯度走就是下山，也就是让损失变小。
- 链式法则 = 逐层乘导数：复合函数求导 = 外层导数 × 内层导数。反向传播就是自动执行这条规则，从输出层一路乘回输入层。

## 2.5 自动微分

### 为什么需要

深网络有百万级参数，手推梯度不现实。自动微分 = 程序记录每一步运算，自动算出任意参数的梯度。

### 计算图直觉（面试高频）

- 每个张量运算是一个节点，节点连起来成一张「计算图」：正向算出输出，反向沿图传梯度。
- 为什么反向传播比前向微分高效：前向微分算 n 个输入的导数要跑 n 遍前向；反向传播跑一遍就能同时拿到**所有**参数的梯度。参数数量远大于输出数量时，差距巨大。

### API 速查

| 操作 | 写法 | 说明 |
|---|---|---|
| 声明需要梯度 | `x.requires_grad_(True)` | |
| 反向传播 | `loss.backward()` | loss 必须是标量 |
| 取梯度 | `x.grad` | |
| 清除旧梯度 | `x.grad.zero_()` | |
| 阻断追踪 | `x.detach()` / `with torch.no_grad():` | 推理时常用，省内存 |

- backward 前不清零，梯度会**累加**到上一次的结果上——第 3 章训练循环的经典 bug 点（面试高频）。
- 标量反向：`y.backward()` 后，每个叶子节点的 `.grad` 里就是 ∂y/∂该节点。

## 2.6 概率

### 为什么需要

数据有噪声、模型输出的是概率、损失函数从概率定义。概率是「不确定性的数学」。

### 基础概念

- 概率分布 / 联合概率 / 条件概率 P(A|B) / 独立事件
- 期望：随机变量按概率加权平均（每种取值 × 它的概率再求和）

### 极大似然估计 MLE（面试高频）

- 想法：已经看到了这批数据，什么样的参数最可能「产生」它们。
- 做法：最大化似然（数据出现的概率）。
- 与损失的联系：最小化「负对数似然」就等于最小化交叉熵 → 这正是第 3 章 softmax + 交叉熵损失的由来。面试必问「为什么最小化交叉熵 = 极大似然」（见 ch03 ex05）。

### 熵（面试高频）

- 熵衡量不确定性：结果越平均（越难猜）熵越大；确定事件熵 = 0。
- 抛硬币类比：公平硬币（正反各 1/2）熵最大；必出正面的硬币熵 = 0。
- 交叉熵：用分布 q 去描述真实分布 p 的代价；KL 散度 = 交叉熵 − 熵，衡量两个分布的差距。第 3 章展开。

## 2.7 查阅文档

### 为什么需要

API 数量庞大，查阅能力比逐一死记更高效。

### 方式

- `dir(module)`：看模块里有什么函数
- `help(func)`：看函数签名与说明
- 官方文档（docs.pytorch.org）+ 搜索引擎：遇到陌生 API 的第一动作
