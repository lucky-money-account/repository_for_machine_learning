## 4.1 多层感知机（MLP）

### 为什么需要

第 3 章的线性模型只能画"直线边界"；真实问题（图像分类、房价）的决策边界是弯曲的。MLP 在输入和输出之间**加一层或多层"隐藏层"**，让模型能拟合非线性的函数。

### 直觉

- 全连接层堆叠：每层 = `线性变换 + 激活函数`
- 前 L−1 层可以看作"**表示学习**"——把原始特征变换成更好用的中间特征；最后一层是线性预测器，负责在这些好特征上做决策
- **万能近似定理**（面试高频）：只要一层隐藏层 + 足够多的神经元，就能以任意精度拟合任意连续函数。这说明"深度不是万能的，但宽度够就能拟合"，也说明 MLP 的表达能力上限很高

### 面试高频追问

- **既然 MLP 能拟合任何函数，为什么还需要 CNN / RNN？**——"能拟合"不等于"学得好"：CNN 用卷积的局部连接/参数共享大幅减少参数、引入空间先验；RNN 处理序列。MLP 全连接对图像/序列是"暴力且低效"的，参数爆炸还容易过拟合。
- **层数越多越好吗？**——不是。更深的网络表达能力强，但更难训练（梯度消失/爆炸、过拟合）；要在"容量"和"可训练性"之间平衡。

## 4.2 激活函数

### 为什么需要非线性（面试高频）

如果每层只是 `线性变换`，那多层线性堆叠后**还是线性**（两个矩阵乘起来还是一个矩阵），加多少层都等于一层。激活函数是让网络"非线性"的关键，没有它，深度就失去了意义。

### 三种常用激活函数

| 函数 | 公式 | 输出范围 | 特点 |
|---|---|---|---|
| ReLU | max(0, x) | [0, +∞) | 主流；正半轴梯度恒 1，训练快 |
| sigmoid | 1/(1+e⁻ˣ) | (0, 1) | 两端饱和，梯度趋 0；现在多用于输出层做概率 |
| tanh | (eˣ−e⁻ˣ)/(eˣ+e⁻ˣ) | (−1, 1) | 零中心；两端同样饱和 |

### 梯度饱和

sigmoid/tanh 在 |x| 很大时，曲线几乎水平，导数 → 0。反向传播时梯度逐层连乘，多个饱和的 sigmoid 叠在一起 → **梯度消失**，参数几乎不更新。

### Dying ReLU（面试高频）

ReLU 在负半轴梯度为 0：如果某个神经元的输入恒为负（比如权重/偏置更新到某个状态），它的输出恒 0、梯度恒 0，这个神经元就"死"了，再也不更新。缓解办法：**Leaky ReLU**（负半轴给一个小斜率如 0.01）、**参数化 ReLU**、或用较小的学习率。

### API 速查

```python
torch.relu(x)      # 或 nn.ReLU()
torch.sigmoid(x)   # 或 nn.Sigmoid()
torch.tanh(x)      # 或 nn.Tanh()
```

## 4.3 从零实现与简洁实现

### 从零（两层 MLP）

```python
num_inputs, num_hiddens, num_outputs = 784, 256, 10
W1 = torch.normal(0, 0.01, size=(num_inputs, num_hiddens), requires_grad=True)
b1 = torch.zeros(num_hiddens, requires_grad=True)
W2 = torch.normal(0, 0.01, size=(num_hiddens, num_outputs), requires_grad=True)
b2 = torch.zeros(num_outputs, requires_grad=True)

def relu(X):
    return torch.max(X, torch.zeros_like(X))

def net(X):
    X = X.reshape((-1, num_inputs))
    H = relu(X @ W1 + b1)          # 隐藏层：线性 + 激活
    return H @ W2 + b2             # 输出层
```

### 简洁（等价写法）

```python
net = nn.Sequential(nn.Flatten(),
                    nn.Linear(784, 256), nn.ReLU(),
                    nn.Linear(256, 10))
```

- 与 softmax 回归的唯一区别：**中间多了一层 `Linear(784,256) + ReLU`**
- 隐藏层的宽度 `num_hiddens=256` 是超参数，通常取 2 的幂

## 4.4 过拟合与欠拟合

### 直觉

- **欠拟合**：模型太简单，连训练数据都拟合不好 → train loss 和 test loss **都高**
- **过拟合**：模型太复杂，把训练数据的噪声都记住了 → **train loss 低、test loss 高**，两者差距大
- 判断标准（面试高频）：看 **train/test 的差距**，不是单看某个绝对值

### 多项式回归演示（书 4.4）

用多项式拟合数据，真实函数是 3 次多项式（加噪声）：

| 模型阶数 | 现象 |
|---|---|
| 阶数 2（太低） | 欠拟合：训练/测试 loss 都高 |
| 阶数 4（恰好） | 训练/测试 loss 都低，差距小 |
| 阶数 20（太高） | 过拟合：训练 loss 极低、测试 loss 飙升 |

模型复杂度（阶数/隐藏单元数/层数）越高，越容易过拟合。

## 4.5 权重衰减（L2 正则化）

### 为什么需要

过拟合常常表现为"权重过大"（模型为了拟合噪声，把某些 w 推得很大）。权重衰减给损失加一个惩罚项，鼓励权重**变小**：

$$L + \frac{\lambda}{2}\|\mathbf{w}\|^2$$

λ 越大，权重被压得越小，模型越"平滑"、越不易过拟合。

### 从零 vs 简洁

```python
# 从零：手写惩罚项
l = loss(net(X), y) + lambd * torch.sum(w.pow(2)) / 2

# 简洁：optimizer 的 weight_decay 参数
trainer = torch.optim.SGD([{"params": net[0].weight, "weight_decay": wd},
                           {"params": net[0].bias}], lr=0.003)   # 偏置通常不衰减
```

### 面试高频

- **为什么 L1/L2 能减缓过拟合**：给大权重加惩罚，等效于"约束模型复杂度"，防止模型死记噪声。
- **L1 vs L2 的几何区别**：L1（|w| 之和）在原点不可导、会直接把部分权重压成**精确的 0**（稀疏）；L2（w² 之和）让权重整体缩小但不归零（平滑）。几何上，L1 的约束区域是菱形、L2 是圆——菱形更容易让最优解落在坐标轴上（权重为 0）。

## 4.6 Dropout（暂退法）

### 直觉

每次训练迭代，随机"关闭"一部分神经元（输出置 0），迫使网络不能依赖任何单个神经元——相当于训练很多个"残缺子网络"的集成，防止过拟合。

### 从零实现

```python
def dropout_layer(X, dropout):
    if dropout == 1:
        return torch.zeros_like(X)
    if dropout == 0:
        return X
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)   # 除以 (1-p) 保持期望不变
```

### 面试高频：train/eval 模式差异（经典 bug 点）

- **训练时**：随机丢弃神经元（dropout 生效）
- **推理时**：**关闭 dropout**，用完整网络
- PyTorch 里 `nn.Dropout` 自动根据 `net.train()` / `net.eval()` 切换；如果忘了 `net.eval()`，推理时 dropout 仍生效，结果会随机且变差。这是最常见的 bug 之一。
- **为什么除以 (1−p)**：丢弃后存活神经元的输出期望变小了，除以 (1−p) 把它补回原尺度，这样推理时（不丢弃）不用再做任何缩放。

## 4.7 前向传播与反向传播

### 计算图

- **前向**：从输入到输出，逐层算值（`z = Wx + b`、`a = relu(z)`、…）
- **反向**：从损失出发，用链式法则逐层把梯度传回参数
- 每个张量运算是一个节点，节点连起来就是计算图

### 面试高频：为什么反向传播比前向微分高效

- **前向微分**：算 n 个参数的梯度要跑 n 遍前向
- **反向传播**：跑**一遍**就能同时得到**所有**参数的梯度
- 因为神经网络的参数数量远大于输出数量，反向传播把复杂度从 O(n 遍) 降到 O(1 遍)，这是它能训练百万参数模型的关键（ex06 会手算验证）

## 4.8 数值稳定性与初始化

### 梯度消失 / 爆炸

- **消失**：多个饱和激活（sigmoid）的导数连乘，梯度趋近 0，浅层参数不更新
- **爆炸**：反复乘大矩阵，值指数级放大（书里用 `M @ M @ ... @ M` 连乘 100 个随机矩阵演示）
- 深层网络尤其容易出现，是"层数越多越难训"的直接原因

### 初始化（面试高频）

- **不能全 0**：所有神经元参数相同 → 梯度也相同 → 每个神经元学到的都一样（对称性），等于只有一个神经元。b 可以全 0（它没有对称性问题）。
- **不能过大**：初始化太大 → 激活进入饱和区 / 前向值爆炸 → 梯度消失或爆炸。
- **Xavier 初始化**（`nn.init.xavier_uniform_`）：根据层宽自动缩放初始值的方差，让**前向和反向的方差都大致不变**，缓解梯度消失/爆炸。直觉：神经元越多，每个权重就该越小，这样总的激活和梯度尺度才稳定。

## 评价指标（一轮必考）

分类问题不能只看"预测对几个"，要用一整套指标。先看**混淆矩阵**：

| | 预测为正 | 预测为负 |
|---|---|---|
| 实际为正 | TP | FN（漏报） |
| 实际为负 | FP（误报） | TN |

- **Accuracy（准确率）** = (TP+TN) / 总数
- **Precision（精确率）** = TP / (TP+FP) —— 预测为正的里面有多少是对的
- **Recall（召回率）** = TP / (TP+FN) —— 实际为正的里面抓出了多少
- **F1-score** = 2·P·R / (P+R) —— Precision 和 Recall 的调和平均，两者都要兼顾时用

### 面试高频：不均衡数据下 Accuracy 会"骗人"

比如 100 个样本里 99 个是负例、1 个正例：一个"永远猜负"的模型 Accuracy = 99%，看着很高，但 Recall = 0——**它一个正例都没抓出来**。所以在类别不均衡时，Accuracy 会掩盖模型的失败，要看 Precision/Recall/F1（或混淆矩阵）。
