## 一、精华问题（本章最有价值的几个追问）

### 1. 为什么房价用 MSE、分类用交叉熵？

- **本质**：任务类型决定损失函数。回归（预测连续值）→ MSE；分类（预测离散类别）→ 交叉熵。
- **深层**：两者是"损失函数 = 概率假设的负对数似然"的两个面孔——回归假设标签服从高斯分布（连续值），分类假设标签服从多项分布（离散类别）。
- **判断口诀**：看到任务先问一句"输出是连续值还是离散类别？"

### 2. 高级 API 到底帮我做了什么？

- **本质**：`nn.Linear` / `nn.MSELoss` / `optim.SGD` / `DataLoader` 只是把从零手写的代码**打包成类**，没有魔法。
- **一一对应**：`w`、`b` 张量 → `nn.Linear`；`linreg` 函数 → `net(X)`；`squared_loss` → `nn.MSELoss`；`sgd` → `optim.SGD`；`data_iter` → `DataLoader`。
- 这是"先手写再简洁"的意义：手写过一遍，才知道简洁实现每行背后在干什么。

### 3. softmax 为什么用 exp？交叉熵为什么推出"梯度 = ŷ − y"？

- **exp**：保证正数 + 放大差距（软版 argmax）。
- **梯度 = ŷ − y**：exp 和 log 在求导中互相抵消，留下最简梯度且无饱和项——对比 MSE 对 softmax 输出的梯度会饱和（预测越离谱梯度越小）。

### 4. 为什么除以 batch_size？（本章问了两次，值得记牢）

- loss 用 `l.sum().backward()` → 梯度是"整批之和"，除以 batch_size 变回"平均"。
- **目的**：解耦 lr 和 batch_size——让调 batch_size 不影响有效学习率。若 loss 用 mean（简洁实现），就不用除。

### 5. 为什么"最小化交叉熵 = 最大化似然"？

- 似然 = 正确类别概率的**乘积** → 取 log 变**求和** → 取负号变**最小化** → 每项 $-\log P(y_i|x_i)$ 就是交叉熵。
- 这条链是"损失函数从哪来"的统一答案，也是 2.6 概率那节"最大似然 → 损失函数"的落地。

## 二、具体体会（几个"原来如此"的时刻）

1. **"损失函数 = 概率假设的负对数似然"** —— 以前以为 MSE 和交叉熵是两个无关公式，现在知道它们是同一框架下高斯/多项假设的两个面孔。这个统一视角是全书损失函数的钥匙。

2. **高级 API 没有魔法** —— 从零手写一遍训练循环后，再看 `nn.Linear` + `optim.SGD` 的简洁实现，突然觉得"这不就是把我手写的那几行包起来了吗"。这种"看穿封装"的感觉，是真正理解框架的关键。

3. **真实数据是"脏活"** —— 前几章都是干净合成数据，第一次碰成都房价（14838 行、16 列、混有"暂无"字符串、有缺失/异常）才体会到"数据预处理占 80% 时间"不是夸张。但拆开看，其实只有 **5 个固定套路**：正则提取、one-hot、填缺失、滤异常、标准化。

4. **loss 卡住不一定是 bug** —— loss 停在 0.27 下不去，第一反应是"没训好"，但算出 R² = 0.73 才发现这是**线性模型的天花板**，不是调参问题。判断"能力上限 vs 没训好"比调参本身更重要。

5. **"数据问题"还是"模型问题"要分清** —— loss 变 NaN，排查顺序固定是"数据有没有 NaN → 标准化有没有除 0 → 学习率是否过大"，90% 死在第一步（数据问题），不是模型问题。

6. **训练/推理特征一致性** —— 预测新样本时，正则、one-hot 列对齐、标准化必须和训练时逐字一致（`reindex` + 复用 `norm()`），否则特征空间不一致、预测就是错的。这比"记公式"更接近工程真相。

## 三、典型问题（踩过的坑）

| 坑 | 现象 | 根因 | 教训 |
|---|---|---|---|
| `return NameError` | `int + type` 报错 | 把**类型对象**当值返回（应 `raise` 或返回 None） | return 和 raise 别混 |
| 返回 None 的列没清理 | loss 全 NaN | parse_floor 返回 None → 楼层位置列 NaN → 标准化 → 喂模型 | 返回 None 的列必须有下游兜底 |
| loss 用 sum 忘除 batch_size | 学习率"被偷改" | 梯度是"和"不是"平均" | sum→除 batch_size；mean→不用除 |
| 批次损失直接平均 | 最后一批被过度加权 | 最后一批样本不满 | `float(l)×len(X)` 加权再除总数 |
| log 套错对象 | log(负数)=NaN | 对标准化标签/可负的 net(X) 取 log | log 只作用在原始正价格上 |
| CrossEntropyLoss 再套 softmax | softmax 两次 | 混淆从零/简洁的 softmax 位置 | 从零 softmax 在 net，简洁在 loss 内部 |
| `flatten()` 替代 `reshape(-1,)` | batch 被拍平 | flatten 全维度拍平 | 用 `flatten(start_dim=1)` 或 `reshape(-1,n)` |
| 优化器绑错模型参数 | loss 恒定不变 | `Adam(net.parameters())` 却训练 net2 | 优化器必须绑定"要训练的那个模型" |

> ch2 已记的**叶子节点、梯度累加、图释放**，本章在真实训练循环里反复实战验证——尤其是"更新必须 `no_grad` + 原地 `-=`"和"前向必须放循环内"。

## 四、本章收获总结

1. **掌握了两类模型**：线性回归（回归/MSE）和 softmax 回归（分类/交叉熵），以及它们共享的统一框架（线性层 + 概率假设 + 最大似然损失）。

2. **吃透了训练循环**：`zero_grad → backward → step` 三件套，以及背后的"为什么"（梯度累加、叶子节点、图释放、batch_size 平均化、加权平均）。

3. **走通了一条真实数据流水线**：成都房价从脏 csv 到 RMSE 5380 元/㎡（R²≈0.72）的完整流程——数据加载 → 特征工程 → 清洗 → 标准化 → 张量 → 训练 → 评估 → 新样本预测。

4. **建立了"数据问题 vs 模型问题"的排查直觉**：loss NaN 先查数据；loss 卡住先算 R² 判断是否能力上限。这是从"会写代码"到"会调模型"的分水岭。

5. **明确了第 4 章的引子**：线性模型 R²=0.73 已是天花板，房价的非线性要靠**多层感知机（MLP）**——加隐藏层 + 激活函数才能拟合。loss 卡在 0.27 的体验，正是进入第 4 章的动机。
