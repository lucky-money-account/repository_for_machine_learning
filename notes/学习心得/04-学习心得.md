## 一、精华问题（本章最有价值的几个追问）

### 1. 为什么单层感知机拟合不了 XOR？

- XOR 的 4 个点在平面上呈**对角线分布**（(0,0)(1,1) 是 0，(0,1)(1,0) 是 1），**线性不可分**——画不出一条直线分开两类。
- 单层感知机 = 线性模型 = 决策边界只能是一条直线 → 无能为力（loss 卡在 0.25 = 只能全猜 0.5）。
- **MLP 解决方式**：加隐藏层 + 非线性激活，把多条直线"折"成曲线边界。

### 2. 万能逼近定理需要会证明吗？

- **不需要**。记住结论（带隐藏层的 MLP 能逼近任意连续函数）+ 它回答的问题（为什么 MLP 比线性模型强）即可。
- 证明属于逼近论/函数分析，工程和面试都用不到（教材自己也只是提结论并指出其局限）。

### 3. 隐藏层为什么必须非线性？输出层为什么不也套 ReLU？

- **隐藏层**：非线性引入"折弯"能力。两层线性 = 还是线性（矩阵相乘合并），白堆层。
- **输出层**：由任务决定——回归用线性输出（输出可负）、二分类 sigmoid、多分类 softmax。ReLU 输出 ≥0 且无上限，既不适合回归也不适合分类。

### 4. ReLU vs sigmoid/tanh 差在哪？

- tanh 相对 sigmoid：**零中心**（sigmoid 恒正 → 梯度方向单一 → zigzag 收敛慢）+ 最大导数 1.0 vs 0.25（梯度消失慢 4 倍）。
- ReLU 相对两者：**正区间导数恒为 1 → 缓解梯度消失**（深网络可行的关键）+ 计算快 + 稀疏激活；缺点是死神经元（x≤0 梯度为 0）。

### 5. 全零初始化会发生什么？

- **线性回归（无隐藏层）**：没问题——凸函数 + 梯度非零，照常收敛。
- **MLP（有隐藏层）**：灾难——所有隐藏神经元对称（权重相同→输出相同→梯度相同→永远相同），N 个神经元退化成 1 个。**随机初始化是为了打破对称性**。

### 6. 过拟合怎么判断？

- **核心依据是"训练损失 vs 验证损失"的差距**：训练低 + 验证高 = 过拟合。最直观是画两条曲线，验证损失出现"先降后升"的 U 形拐点。
- 训练损失不是"小模块"——它是**健康监控器**：loss 不降 = 没在学、NaN = 数据问题、训练/验证差距 = 过拟合警报。

## 二、综合题「MLP 拟合 2D 函数」的具体体会

1. **训练 loss 低 ≠ 范围外正确**——loss 只在训练范围 [-2,2]² 内算（0.0025），外推到 [-5,5]² 就乱。**MLP 能内插、不能外推**：ReLU 是分段线性，范围外没有数据约束，直线段沿学到的斜率无限延伸，完全偏离真实的周期函数。

2. **模型会拟合"数据里的一切"**——噪声从 0.05 加到 0.5，模型从拟合真实 sin·cos 变成拟合噪声（loss 0.003 → 0.24，曲面出现毛刺）。**什么时候拟合噪声？** 模型容量足够大、又没有任何约束（正则）时。

3. **正则化的实际效果被自己验证**：基线 MSE 0.0136 > weight_decay 0.0091 < Dropout 0.0114——weight_decay 最有效。这呼应了"参数量定上限、λ 定用法、验证集选组合"的理解。

4. **学习率的直观感受**：lr=0.1 收敛最快最彻底（0.0098），lr 每降 10 倍效果明显变差（0.0001 时还停在 0.24）——学习率是"步子大小"，太小走不到底。

## 四、本章收获总结

1. **MLP 从动机到实践闭环**：XOR 线性不可分 → 加隐藏层+激活 → 拟合 sin·cos 非线性函数成功（loss 0.003）。
2. **三大能力边界**：能内插不能外推；容量够大就会拟合噪声；正则化（wd/Dropout）压制过拟合但各有强弱。
3. **超参数直觉**：lr 定步子大小；深度/宽度定容量上限；λ 定泛化 vs 拟合的平衡。
4. **可视化代码是"脚手架"不是核心知识**——meshgrid/stack/reshape/plot_surface 记成固定模板（已封装进 `utils/visualization.py`），别让工具语法打击深度学习信心。
